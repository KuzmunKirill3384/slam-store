# SLAM STORE

Telegram Mini App магазина архивной одежды со встроенной админкой. Сервера нет: сайт живёт на GitHub Pages, каталог лежит в `store.json`, админка правит его коммитами через GitHub API. Всё бесплатно.

```
index.html   приложение целиком: витрина и админка
store.json   товары, бренды, настройки витрины
img/         фото товаров, создаётся админкой сама
```

## Запуск

**1. GitHub Pages**

1. Создай публичный репозиторий, например `slam-store`
2. Загрузи `index.html` и `store.json`
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`
4. Через минуту сайт будет на `https://<логин>.github.io/slam-store/`

**2. Бот**

1. В @BotFather: `/newbot`, имя и username, например `slamstore_bot`
2. `/mybots` → бот → Bot Settings → Menu Button → ссылка с GitHub Pages, текст «Магазин»
3. `/newapp` → тот же бот, та же ссылка, короткое имя `shop`. Получится `https://t.me/slamstore_bot/shop`

**3. Токен для админки**

1. Открой [создание токена](https://github.com/settings/personal-access-tokens/new)
2. Repository access: **Only select repositories**, выбери `slam-store`
3. Permissions → Repository permissions → **Contents: Read and write**. Остальное не трогай
4. Срок действия: год. Скопируй токен

**4. Вход в админку**

1. Открой магазин в Telegram. Вкладка «Админ» видна только тем, кто указан в `settings.admins` в `store.json` (username или Telegram ID)
2. Вставь токен, репозиторий подставится сам. Токен подтянется на другие устройства через облако Telegram
3. Чтобы добавить или убрать админа, измени поле «Админы» в разделе «Витрина» и нажми «Сохранить витрину». Новому админу нужен свой токен: создай отдельный по шагам выше и передай лично, тогда его можно будет отозвать, не трогая свой

Вне Telegram админка открывается по адресу сайта с `#admin` на конце.

## Работа с каталогом

- **Добавить вещь:** «Добавить вещь» → «Вставить пост из канала», вставь текст поста как есть, поля заполнятся сами. Проверь, добавь фото, «Сохранить»
- **Продано или бронь:** переключатель статуса прямо в списке вещей, без открытия формы
- **Фото:** сжимаются на телефоне до 1400 px. Первое фото будет обложкой, любое можно сделать обложкой кнопкой на нём
- **Лот недели, контакты, бегущая лента, ссылка на Mini App:** раздел «Витрина»
- **Новый бренд:** в форме выбери «+ Новый бренд». У четырёх основных брендов свои заглушки, у новых цвет подбирается автоматически

После сохранения изменения появляются у покупателей примерно через минуту, пока GitHub Pages пересобирает сайт. У тебя в админке они видны сразу.

## Безопасность

- Список админов только показывает вкладку. Менять каталог может лишь тот, у кого есть токен с правами на запись
- Токен хранится только на твоих устройствах и в облаке Telegram у твоего аккаунта в этом боте. В репозиторий и `store.json` он не попадает
- Если телефон потерян: удали токен на GitHub в Settings → Developer settings → Personal access tokens, затем создай новый
- Кнопка «Отключить это устройство» в админке стирает токен с устройства и из облака
